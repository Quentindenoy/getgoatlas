What does Go Glow do?

It adds a glow after any text, image or video. The glow is added in linear light and fades with distance the way real light does: tight near the source, soft far away. Small shapes and dark features keep their edges, even when the glow is pushed hard, and the output is dithered so the halo stays smooth on dark backgrounds.

Which controls does it have?

Glow sets the size and the strength together. Threshold sets how bright a pixel must be before it glows, and Threshold Softness eases the glow in around that threshold. Those three run from 0 to 100, and each defaults to 50. Tint shifts the colour of the glow (Red, Green, Blue) and stays collapsed until you need it. Quality trades a little detail for speed on heavy projects: Full, Half or Quarter.

What machine do I need?

Windows and DaVinci Resolve, which is sold separately by Blackmagic Design. On NVIDIA graphics cards Go Glow renders on the GPU with CUDA, currently enabled for DaVinci Resolve 21.1. Everywhere else it uses a multi-threaded CPU path, so it still works.
